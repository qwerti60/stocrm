Зачем своё приложение

STOCRM уже ведёт клиентов, авто и заказ-наряды. Штатное приложение вендора — для сотрудников. Клиентам — своё приложение VAG Market: запись, история, статусы и push (готовность, акции, бонусы), чат с именем менеджера.

Клиент

  • Вход по телефону (OTP)
  • Гараж: номер, марка, пробег, VIN
  • Запись: авто → филиал → слот
  • История: работы, запчасти, пробег
  • 3 филиала, карта 2ГИС / Яндекс
  • Статусы, чат, бонусы 5%, VIN-заявка

Интеграция

  • SID только на сервере
  • Сделка offer/new/with_contact
  • Источник «Онлайн-запись»
  • Контакт по телефону, без дублей
  • Кэш каталога работ
  • Журнал заявок, если CRM недоступна

Push и сервис

  • Запись без звонка, слоты по филиалам
  • Push «Ваша машина готова!»
  • Рекомендации мастера из CRM
  • Чат: имя менеджера, ответы из админки
  • Массовые акции в push
  • Виджет «пора в сервис»

Полное ТЗ (v1.1, согласовано на встрече): tz.html.
