Политика обработки персональных данных

Клиентское приложение VAG Market · 152-ФЗ · редакция 21.09.2026

Настоящий документ описывает, какие данные обрабатывает приложение VAG Market и зачем. Оператор учёта заказов — сервис VAG Market (ИП Гоман Павел Игоревич, сайт vagmarket72.ru). Учётная система — STOCRM кабинета Заказчика.

1. Какие данные

  • Номер телефона — вход по коду, поиск карточки клиента в STOCRM.
  • Имя и контакт из CRM, если телефон уже есть в базе сервиса.
  • Автомобили: марка, модель, госномер, VIN, пробег — из карточки клиента в STOCRM.
  • Заявки на запись, сообщения чата, VIN-заявки на подбор запчасти.
  • Токен устройства для push (когда подключим Firebase).

2. Зачем

  • Запись на сервис и подтверждение заявки менеджером.
  • История заказ-нарядов, статус ремонта, «машина готова».
  • Чат с сервисом и подбор запчасти по VIN (не интернет-магазин склада).
  • Бонусы 5% с закрытого заказ-наряда и напоминание о сгорании.
  • Рассылки акций, на которые вы согласились, пользуясь приложением.

3. Где хранится

Ключ API STOCRM хранится только на сервере приложения (VPS в РФ), не в телефоне. Переписка чата и журнал бонусов — на том же сервере. Сделки и карточки клиентов — в STOCRM Заказчика.

4. Передача

Данные передаются в STOCRM для учёта визитов. SMS-шлюз и Firebase — когда Заказчик подключит их ключи. Складской остаток клиенту не отдаём. Третьим лицам для рекламы вне сервиса не продаём.

5. Срок и отзыв

Пока вы пользуетесь приложением и есть карточка в CRM сервиса. Чтобы удалить данные приложения (чат, журнал бонусов) или отозвать согласие — напишите в чат приложения или на точку из раздела «Адреса». Данные в STOCRM правит сервис как оператор учёта.

6. Согласие

Вводя телефон и код, вы соглашаетесь на обработку указанных данных для записи, статуса ремонта, чата и сервисных уведомлений. Рассылки акций можно отключить, отказавшись от push в профиле, когда системные уведомления будут подключены.
