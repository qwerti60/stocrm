Как пользоваться приложением VAG Market

Клиенту сервиса. Прототип: вход по коду 1234, запись подтверждает менеджер звонком.

← Хаб QA Менеджеру
Это тестовая сборка. СМС с кодом пока не приходит — введите 1234. После записи ждите звонка или сообщения, слот не «бронь в календаре» до подтверждения.

1. Первый запуск

  1. Откройте приложение. Сначала короткое видео (шортсы) — листайте, затем «Дальше».
  2. Введите 10 цифр номера без +7 (например 9139142994).
  3. Нажмите «Получить код», введите 1234.
  4. Разрешите уведомления, если спросит (в тесте можно пропустить).

2. Вкладки

ВкладкаЧто внутри
ГлавнаяАвто, ближайшая запись, акции, быстрые кнопки
ГаражВаши машины из карточки клиента в сервисе
ЗаписьВыбор авто, филиала, времени, услуги
АдресаТочки VAG Market / NIN HAO, телефон, часы
ЧатыПереписка с сервисом (пока демо)
ПрофильБонусы, согласия, выход

3. Как записаться

  1. Гараж: выберите машину (если список пустой — записывайтесь без авто, менеджер уточнит).
  2. Запись: филиал → услуга → день и время.
  3. Подтвердите. Текст на экране: заявка принята, ждите подтверждения.
  4. Не приезжайте, пока не перезвонили / не написали из сервиса.

4. Гараж и VIN

  • Машины подтягиваются из STOCRM по вашему телефону.
  • Если авто нет в списке — его нет в вашей карточке клиента. Скажите администратору на точке.
  • VIN-заявка (подобрать деталь) — в меню, ответ будет в чате или звонком. Сейчас это прототип.

5. Статус ремонта

Когда машина в сервисе, на главной появится статус (в работе / готова). Push «Ваша машина готова!» подключим на следующей неделе. Пока смотрите статус в приложении или звоните на точку.

6. Если что-то не так

  • Код не 1234 — ошибка, повторите.
  • Нет интернета — вход и запись не уйдут в сервис.
  • Не пришёл звонок после заявки — позвоните на филиал из вкладки «Адреса».
